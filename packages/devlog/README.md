# @aribradshaw/devlog

Headless DevLog primitives for projects that need one release model without sharing one visual design.

The package owns portable concerns such as author metadata, commit resolution, feature policies, filtering, pagination, and safe GitHub URLs. Host applications own rendering, styling, data storage, authentication, deployment lifecycle details, and the decision to expose or hide each capability.

Audio Browser Lab is the first integration pilot. The package is not published to npm yet.
